## 📖 Project Overview

**Kasper** is a comprehensive template designed for creative portfolios and agencies.

Following my initial foundational projects, Kasper was built to push my skills further by integrating **Vanilla JavaScript** for interactivity, handling multimedia (video integration), and building more complex UI structures like pricing tables, stat counters, and image galleries entirely from scratch.

---

## ✨ Key Features

- **Dynamic Interactivity:** Utilized Vanilla JavaScript for DOM manipulation, mobile menu toggling, and interactive UI components.
- **Multimedia Integration:** Implemented a seamless HTML5 background video (`<video>`) natively within the portfolio section.
- **Complex UI Components:** Built detailed sections including responsive pricing tables, testimonials, and dynamic skill progress bars.
- **Fluid Responsiveness:** Ensured perfect rendering across all devices (Mobile, Tablet, Desktop) using custom Media Queries and Flexbox.
- **Clean Architecture:** Maintained a well-organized file structure separating structure (HTML), presentation (CSS), and behavior (JS).

---

## 🛠️ Tech Stack & Tools

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, CSS Variables, Advanced Selectors)
- **Scripting:** Vanilla JavaScript (DOM Manipulation)
- **Typography & Icons:** Google Fonts (_Open Sans_), Font Awesome
- **Version Control:** Git & GitHub

---

## 🧠 Key Learnings

Developing Kasper was a significant milestone that taught me how to:

1. Integrate and manage Vanilla JavaScript to bring static HTML/CSS to life.
2. Handle responsive multimedia elements without degrading performance.
3. Structure complex, multi-layered CSS for larger projects while avoiding global styling conflicts.
4. Build reusable UI patterns (like cards, grids, and forms) from the ground up.
